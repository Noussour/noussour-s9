Box2DWeb: Collision Detection

Practical sheet · Contact listeners and collision events

Creating and registering the listener

Create the listener after creating the Box2D world, then register it with that world:

var listener = new Box2D.Dynamics.b2ContactListener();

// Called when two fixtures start touching
listener.BeginContact = function(contact) {
    console.log("Collision started!");
};

// Called when two fixtures stop touching
listener.EndContact = function(contact) {
    console.log("Collision ended!");
};

// Register the listener with the world
world.SetContactListener(listener);
Important: Register the listener once, after the world has been created. The callbacks are invoked by Box2D during the simulation; do not call them manually.

Adding an action when a collision occurs

The contact callback can also trigger an action in the application. For example, the following code counts the number of new contacts detected:

var collisionCount = 0;

listener.BeginContact = function(contact) {
    collisionCount++;
    console.log("Collision count: " + collisionCount);
};

listener.EndContact = function(contact) {
    console.log("Contact ended.");
};

Another possibility is to play a sound when contact begins:

// Make sure the sound file is available to the web page.
// Browsers may require the user to click a Start button first.
var collisionSound = new Audio("collision.mp3");

listener.BeginContact = function(contact) {
    collisionSound.currentTime = 0;
    collisionSound.play();
};

The sound file path must be correct. The example plays a sound for every new contact, so several simultaneous contacts may trigger several playback requests.

Application

Objective: Combine the static platform and dynamic object, then detect their collision.
  1. Combine the two supplied programs into one application using a single Box2D world.
  2. Create and register a contact listener.
  3. Display a message in the console when contact begins and when it ends.
  4. Change the restitution (bounciness) of the dynamic object's fixture and observe the result.
