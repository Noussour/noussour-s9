## Structure

Each module folder follows the same layout:

- `COURS`: course chapters, named `Chapter<N>_<Module>.pdf`
- `TD`: exercise sheets and solutions, one folder per TD
- `TP`: practical work
- `RESUME`: summaries (added as we go)
