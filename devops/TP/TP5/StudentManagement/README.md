# Student Management System
A small web application used to practise Git.

## Features
- Student registration form.
- Introductory Git and GitHub exercises.

This is a static teaching example; it does not store registrations.

## Git practice
Use focused commits and inspect staged changes before committing.

Local experiments can be undone before publication.

Stash temporarily saves unfinished tracked work.

A fast-forward moves a branch pointer without a merge commit.
